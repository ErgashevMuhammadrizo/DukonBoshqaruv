# e-dukon — kategoriya va mahsulot manzili

Mahsulotlar oynasining yuqorisida kategoriyalar hamda “Yangi kategoriya” tugmasi mavjud. Mahsulot bo‘lmasa ham kategoriya yaratish mumkin. Barchasi tugmasi kategoriya filtrini tozalaydi. Yangi mahsulot va tahrirlash oynasida kategoriya tanlash hamda shu joydan yangi kategoriya yaratish mumkin; yaratilgan kategoriya avtomatik tanlanadi.

Mahsulot manzili uchta matn maydoni: Ombor, Bo‘lim, Polka. Har biri 100 belgigacha, ixtiyoriy. Misol: Asosiy ombor → Elektronika → B-3, 2-polka. Manzil kartada, ro‘yxatda, batafsil oynada va Kassada ko‘rinadi. Mahsulotlar qidiruvi manzilni ham qidiradi. Eski mahsulotlarda maydonlar bo‘sh bo‘ladi; majburan to‘ldirish shart emas.

Bu manzil yorlig‘i. Bir mahsulot bir nechta omborda alohida qoldiq bilan yuritilmaydi; mavjud yagona qoldiq va POS hisoblashlari saqlanadi.

Kategoriya yaratish internet talab qiladi: server tasdiqlamaguncha saqlangan deb ko‘rsatilmaydi. Mavjud kategoriya va manzillar katalog keshi bilan offline o‘qiladi. Shu do‘konda takroriy kategoriya nomi (katta-kichik harfdan qat’i nazar) rad etiladi. Boshqa do‘kon kategoriyasini mahsulotga ulash mumkin emas.

Yangilash: bazani backup qiling va backend ichida python manage.py migrate bajaring. So‘ng ilovani qayta yig‘ing. Ko‘rinadigan nom e-dukon. Ilova application ID, lokal baza nomi va API domeni saqlangan: mavjud o‘rnatmani bir xil signing key bilan yangilash mumkin. Eski fayl/papka nomlarining ayrimlari texnik moslik uchun saqlangan.

inPAY v2 va Windows tuzatishlari oldingi versiyadan saqlangan. Flutter build/widget testlari hamda haqiqiy Windows qurilma sinovi bu muhitda bajarilmagan; oldingi cheklovlar MVP_TEKSHIRUVLAR_UZ.md da keltirilgan.
