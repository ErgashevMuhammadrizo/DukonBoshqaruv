# APK joyi
Faqat tayyor, imzolangan Android APK faylni shu papkaga `dokon-boshqaruv.apk` nomi bilan joylang.
Public URL: `/downloads/dokon-boshqaruv.apk`. Fayl hozir bu arxivga qo‘shilmagan.
Boshqa faylga shu nomni berib qo‘ymang. Haqiqiy APK ZIP formatida bo‘ladi; server noto‘g‘ri faylni yuklatmaydi.
Asosiy sozlama: website/site_config.json → download_url. Versiya aniq bo‘lsa apk_version ni to‘ldiring.
